# XREAL One Pro — русское меню

Неофициальный проект русификации **XREAL One Pro** с приложением для установки на Windows. Русский язык заменяет польский пункт меню, английский остаётся доступен.

Переведены 437 строк интерфейса. Внешние и встроенные шрифты дополнены кириллицей, чтобы устранить квадратики вместо русских букв.

Это один переносимый EXE размером около 100 МБ. Его достаточно скачать и запустить: устанавливать Python, распаковывать архивы или отдельно искать файл прошивки не нужно. Прошивка встроена; после скачивания интернет для работы приложения не требуется.

## Совместимость

| Требование | Поддерживается |
| --- | --- |
| Компьютер | Windows 10/11, x64 |
| Очки | XREAL One Pro |
| Версия SoC | `15.1.03.603_20260914` |
| Версия Pilot | `1.9.1.20260914175625` |
| SKU | `X1112010` |
| Подключение | USB-кабель с передачей данных |

Приложение проверяет версии перед записью. При несовпадении установка блокируется. Совместимость с другими версиями, XREAL One, Air и другими моделями не заявлена.

## Как установить русское меню

1. Скачайте **XREAL-Russian-Updater.exe** по ссылке выше и запустите его. Для обновления самого приложения закройте предыдущую версию и запустите новый файл.
2. Подключите очки к компьютеру USB-кабелем с передачей данных. Закройте страницу обновления XREAL в браузере и другие программы, работающие с очками.
3. Нажмите **«Обновить список»** и выберите нужные очки в выпадающем списке.
4. Нажмите **«2. Установить прошивку»**. Приложение проверит встроенный пакет, модель и версии устройства, затем начнёт передачу.
5. Дождитесь сообщения **«Готово. Файлы проверены»**. После передачи очки перезапускаются; приложение затем считывает пять изменённых файлов и сравнивает их с пакетом. Не отключайте USB и питание до завершения.
6. Отключите очки от компьютера и подключите к телефону или другому источнику видео. Откройте выбор языка в меню очков: русский занимает место польского. Если ранее был выбран другой язык, переключитесь на **«Русский»**.

Для установки достаточно USB-соединения; видеовыход компьютера не требуется. Чтобы увидеть меню в очках, нужен источник видео.

**Важно:** это экспериментальная модификация, не официальный выпуск XREAL. Приложение не создаёт полный резервный образ устройства; прерывание записи может нарушить его работу. EXE не подписан сертификатом издателя, поэтому Windows может показать предупреждение о неизвестном издателе.

## Если прошивка уже установлена

Выберите очки и нажмите **«Проверить без записи»**. Приложение прочитает файлы и сравнит их с текущей сборкой, не прошивая устройство повторно. После успешной проверки очки можно отключить.

Эта кнопка полезна, если пакет был передан, но USB-соединение прервалось при последующей проверке. Ошибка проверки сама по себе не означает, что запись прошивки не удалась.

## Если что-то не работает

| Ситуация | Что сделать |
| --- | --- |
| Очки не отображаются | Проверьте кабель с передачей данных и USB-порт, затем нажмите «Обновить список». |
| Сообщение о неподдерживаемой версии | Сверьте версии с таблицей совместимости. Эта сборка не предназначена для обнаруженной конфигурации. |
| Пакет принят, но проверка файлов не завершена | После сообщения об ошибке переподключите очки, выберите их заново и нажмите «Проверить без записи». |
| Ошибка во время передачи пакета | Сохраните текст ошибки и журнал. Не считайте установку завершённой и не запускайте повторные попытки вслепую. |
| Не видны нижние кнопки | Используйте колесо мыши, полосу прокрутки или Tab. Окно можно изменять по размеру. |
| В старом приложении появляется `1025/513` | Скачайте актуальный EXE; ошибка обработки размера USB-отчёта исправлена. |

Журнал последней ошибки: `%LOCALAPPDATA%\XREAL-Russian-Updater\last-error.txt`.

[Сообщить о проблеме](https://github.com/Skiters/xreal-one-pro-russian/issues): укажите версию приложения, этап сбоя, текст ошибки и версии очков. Перед публикацией журнала проверьте, нет ли в нём личных данных.

## Что умеет приложение

- Выбор подключённых очков и проверка совместимости до записи.
- Установка по HID-протоколу, использованному веб-обновлятором XREAL.
- Индикатор этапов и прогресса, ожидание перезапуска устройства.
- Проверка пяти установленных файлов; ограниченные повторы чтения при обрыве связи без автоматической повторной прошивки.
- Отдельная проверка без записи.
- Размер окна с учётом экрана и масштаба Windows, перенос текста и прокрутка.

## Статус проверки

- Пакет установлен на физических XREAL One Pro; все пять изменённых файлов считаны обратно и совпали со сборкой.
- После перезапуска меню в журнале отсутствовали предупреждения о недостающих символах. Визуальная проверка всего русского меню пользователем пока не подтверждена.
- Проверка файлов через собранный EXE v0.1.2 выполнена на устройстве. Полный цикл установки через текущую v0.1.3 пока не проверен.
- Для v0.1.3 прошли 16 автоматических тестов и проверка запуска собранного EXE. Доступность элементов проверена в окне 420×280 при масштабе 100%, 150% и 200%.
- Для встроенных шрифтов выполнены 2145 эмуляционных проверок штатного ARM64 обработчика; исправлены 868 случаев отсутствующих символов, метрики ранее доступных символов сохранены.

Сборка приложения из готового пакета автоматизирована. Полная сборка самой модифицированной прошивки с чистого клона пока не автоматизирована: требуются локальные исходные компоненты Pilot и шрифты, не включённые в репозиторий.

Пакет изменяет компонент **Pilot**, а не всю память очков. SHA256 пакета `XREAL_One_Pro_Pilot_RU.bin`:

```text
135ff3fee312361323af11e03dac7edf779cf4386cd1a858f767e1320b3e988e
```

Контрольная сумма приложения EXE публикуется отдельно в `SHA256SUMS.txt` на странице выпуска.

Резервные копии устройства, сырые журналы и браузерный кэш не входят в репозиторий. Проект не связан с XREAL; права на оригинальные компоненты производителя и сторонние шрифты сохраняются за их правообладателями.
