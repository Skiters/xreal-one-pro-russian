# XREAL One Pro: русское меню

Экспериментальная русификация компонента Pilot версии `1.9.1.20260914175625` для XREAL One Pro. Русский заменяет польский пункт меню; английский сохранён.

## Установка на Windows

[Скачать XREAL-Russian-Updater.exe](https://github.com/Skiters/xreal-one-pro-russian/releases/tag/v0.1.2-windows) (Windows 10/11 x64). Запустите EXE, подключите очки, выберите их в списке и нажмите «Установить русскую прошивку». Прошивка уже внутри; Python и ручная работа с файлами не нужны. Дождитесь завершения проверки перед отключением очков. Если пакет уже передан, используйте «Проверить без записи».

[Описание приложения и сборки](installer/README.md). EXE не подписан сертификатом издателя. При установке через v0.1.1 устройство приняло пакет; USB-соединение оборвалось на последующей проверке. Отдельное чтение подтвердило совпадение всех пяти файлов. v0.1.2 восстанавливает соединение для повторной проверки без повторной записи; полный цикл установки через v0.1.2 пока не проверен.

## Результат

Переведены 437 непустых английских строк. Кириллица добавлена в два внешних TTF и в цепочки подстановки 15 встроенных растровых шрифтов LVGL. Недостающие символы встроенных шрифтов были причиной квадратиков. Исходный машинный код функций не изменён.

Готовый пакет: `outputs/xreal-russian-firmware/XREAL_One_Pro_Pilot_RU.bin`.

SHA256: `135ff3fee312361323af11e03dac7edf779cf4386cd1a858f767e1320b3e988e`.

Это пакет Pilot, а не образ всей памяти очков. Устройство, на котором выполнена установка: SoC `15.1.03.603_20260914`, SKU `X1112010`.

## Проверка

- 2145 проверок штатного ARM64 обработчика шрифтов в эмуляторе; исправлены 868 случаев отсутствующих символов.
- Сохранены метрики ранее доступных символов; проверена целостность архива и контрольные суммы файлов.
- После установки пять изменённых файлов считаны с устройства и побайтно сопоставлены со сборкой.
- После перезапуска меню инициализировалось без предупреждений об отсутствующих символах.
- Визуальная проверка пользователем пока не подтверждена.

Отчёты находятся в `outputs/xreal-russian-firmware/`. Перевод в CSV и таблице для просмотра — в `outputs/xreal-russian-translation/`.

## Инструменты

Скрипты в `work/`: сборка ресурсов (`build_russian_pilot.py`), исправление встроенных шрифтов (`patch_embedded_fonts.py`), эмуляционная проверка (`test_embedded_fonts.py`), упаковка (`pack_pilot.cjs`), установка (`flash_russian_pilot.py`), чтение и проверка (`verify_russian_pilot.py`, `xreal_usb_probe.py`). Python-зависимости: fonttools, Pillow, lief, pyelftools, unicorn, hidapi; упаковка использует Node.js. Патч создавался с LIEF 1.0.0 и Python 3.13.

Это сохранение рабочего проекта. Полная сборка с чистого клона пока не автоматизирована: скрипты используют локальный исходный ZIP Pilot, исходную `libnr_osd.so`, архив MiSans Latin и промежуточный пакет с дополненными TTF. Эти исходные и промежуточные бинарные файлы не входят в Git. Не запускайте сборочные скрипты без подготовки их входных файлов; порядок зависимостей виден в исходниках.

`python work/flash_russian_pilot.py` проверяет готовый пакет без записи. Только явный аргумент `--flash` включает установку через HID. `python work/verify_russian_pilot.py` требует локальный `work/update-analysis/pilot-russian.zip` для сравнения. Не используйте пакет для других моделей или версий без отдельной проверки.

Полный резервный образ устройства не получен. Частичные резервные копии, сырые журналы, идентификаторы устройства, сторонние зависимости и браузерный кэш исключены из Git. Оригинальные компоненты производителя внутри готового пакета сохраняют права их правообладателей.
