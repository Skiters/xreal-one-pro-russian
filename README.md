# XREAL One Pro — русское меню

Неофициальная русификация XREAL One Pro с приложением для установки на Windows. Переведены **437 строк интерфейса**. Русский язык занимает место польского, английский остаётся доступен.

**Текущая версия — v0.2.1: поддержка SKU X1112010 и X1112011, единые шрифты.** Кириллица, латиница, цифры и знаки теперь используют согласованное начертание внутри каждого стиля меню. Прежнее смешение исходных символов с отдельно подобранными русскими буквами устранено. Пакет прошивки тот же, что в v0.2.0: пользователь установил его на X1112010 и 15 октября 2026 года подтвердил, что всё отлично работает.

## Совместимость

| Параметр | Поддерживаемая конфигурация |
| --- | --- |
| Компьютер | Windows 10/11 x64 |
| Очки | XREAL One Pro |
| SoC | `15.1.03.603_20260914` |
| Pilot | `1.9.1.20260914175625` |
| SKU | `X1112010`, `X1112011` |
| Кабель | USB с передачей данных |

В v0.2.1 добавлен SKU `X1112011`: в v0.2.0 установщик ошибочно ограничивался только `X1112010`. Пакет прошивки не изменён. [Основание совместимости](installer/compatibility.md). Установка на `X1112010` проверена пользователем; подтверждение установки на `X1112011` пока ожидается.

Приложение проверяет модель и версии перед записью. Несовместимая конфигурация отклоняется. Поддержка других моделей и версий прошивки не заявлена.

## Установка

1. Скачайте EXE по ссылке выше. Закройте старое приложение, если оно запущено, и откройте новое. В заголовке должна быть версия **v0.2.1**.
2. Подключите очки к компьютеру кабелем с передачей данных. Закройте страницу обновления XREAL и другие программы, использующие очки.
3. Нажмите **«Обновить список»** и выберите нужное устройство.
4. Нажмите **«2. Установить прошивку»**. Приложение проверит пакет и совместимость, передаст прошивку и дождётся перезапуска.
5. Не отключайте USB и питание. Дождитесь сообщения **«Готово. Файлы проверены»**: после записи приложение считывает пять изменённых файлов и сравнивает их с пакетом.
6. Отключите очки и подключите телефон или другой источник видео. В меню языков выберите **«Русский»**, который занимает место польского.

Для прошивки компьютеру не нужен видеовыход по USB-C. Для просмотра меню в очках нужен источник видео.

Если установлена старая русификация, установите новый пакет тем же способом. Если уже установлена локальная сборка **XREAL-Uniform-Fonts-Local** с едиными шрифтами, повторная прошивка ради v0.2.1 не нужна: внутри тот же пакет. Можно воспользоваться проверкой без записи.

## Проверка без повторной прошивки

Выберите очки и нажмите **«Проверить без записи»**. Приложение только прочитает файлы и сравнит их с текущим пакетом.

Если пакет был принят, но USB оборвался на последующей проверке, дождитесь сообщения об ошибке, переподключите очки и выполните эту проверку. Сам по себе сбой чтения не означает неудачную запись. Автоматической повторной прошивки после ошибки нет.

## Что изменилось в шрифтах

- В каждом из **15 встроенных стилей** пересобраны **166 символов**: русский алфавит, латиница ASCII, цифры и нужная пунктуация.
- Кириллица и латиница одного стиля рисуются одним шрифтом из семейства MiSans Latin. Два внешних TTF согласованы с тем же источником.
- Высоты строк сохранены. Для самого тесного стиля размер и вертикальное положение подобраны так, чтобы помещались диакритика и нижние части букв.
- Исходные значки и символы других языков остаются доступны через исходные наборы. Английские тексты не изменены; их начертание обновлено вместе с русским.
- Размеры заголовков и обычного текста по-прежнему отличаются по назначению.

[Предпросмотр всех стилей](outputs/xreal-russian-firmware/font-preview.png) показывает реальные растры новой сборки, а не фотографию экрана очков.

## Возможности Windows-приложения

Выбор устройства, проверка совместимости и целостности пакета, индикатор прогресса, ожидание перезапуска, проверка записанных файлов и восстановление соединения для повторного чтения. Интерфейс учитывает размер экрана и масштаб Windows, переносит текст и поддерживает прокрутку колесом, полосами и переходом Tab.

## Решение проблем

| Ситуация | Что делать |
| --- | --- |
| Очки отсутствуют в списке | Проверьте USB-порт и кабель с передачей данных, нажмите «Обновить список». |
| Версия не поддерживается | Сверьте её с таблицей совместимости. Не используйте эту сборку для другой конфигурации. |
| Пакет принят, проверка не завершена | После сообщения об ошибке переподключите очки и нажмите «Проверить без записи». |
| Сбой во время передачи | Сохраните текст ошибки и журнал; не считайте установку завершённой. |
| Нижние элементы не видны | Прокрутите колесом, полосой прокрутки или перейдите к кнопке клавишей Tab. |
| Ошибка `1025/513` в старом EXE | Загрузите актуальный выпуск: обработка размера USB-отчёта исправлена. |

Журнал ошибки: `%LOCALAPPDATA%\XREAL-Russian-Updater\last-error.txt`.

[Сообщить о проблеме](https://github.com/Skiters/xreal-one-pro-russian/issues): укажите версию приложения, версии очков, этап сбоя и текст ошибки. Проверьте журнал на личные данные перед публикацией.

## Проверки и ограничения

Текущий пакет установлен и проверен пользователем на физических XREAL One Pro; внешний вид и работа подтверждены. Это проверка на конкретном устройстве, а не гарантия для всех сценариев и источников видео.

Для новых шрифтов выполнены **2490 проверок получения символов**, **2460 проверок растров** и **75 проверок исходных резервных символов** штатными ARM64-функциями в эмуляторе. Для внешних TTF проверены **332 пары контуров и метрик**. Все новые символы помещаются по высоте строки. Проверены архив и контрольные суммы; код функций прошивки не изменён.

Для приложения предусмотрены 18 автоматических тестов, включая интерфейс при 100%, 150% и 200% масштабе. Полный автоматический обход всех меню и измерение ширины каждой подписи не выполнялись. Старые журналы чтения устройства не выдаются за проверку текущего пакета; подтверждение пользователя отмечено отдельно в отчётах.

**Неофициальная экспериментальная модификация.** Полный резервный образ не создаётся. Прерывание записи может нарушить работу очков. EXE не подписан сертификатом издателя, поэтому Windows может показать предупреждение об неизвестном издателе.

Сборка Windows-приложения из включённого в репозиторий готового пакета автоматизирована. Для пересборки самой прошивки нужны локальные исходный архив Pilot, оригинальная библиотека OSD и архив MiSans Latin; полный цикл с чистого клона пока не автоматизирован. Старые скрипты `build_russian_pilot.py` и `patch_embedded_fonts.py` сохранены для истории предыдущего способа подстановки, не для текущей сборки.

SHA256 текущего пакета `XREAL_One_Pro_Pilot_RU.bin`:

```text
258ecdb3a9892c7a2bf700c4f0fbccf52ced8915081c0109beb08c59c60418ec
```

Это обновление компонента **Pilot**, а не полный образ памяти. Контрольная сумма EXE находится в `SHA256SUMS.txt` на странице выпуска. Резервные копии, сырые журналы и браузерный кэш не публикуются. Проект не связан с XREAL; права на исходные компоненты и сторонние шрифты остаются у правообладателей.
