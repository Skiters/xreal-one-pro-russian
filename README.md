# XREAL One / One Pro / 1S — русская прошивка и установщик Windows

Неофициальная русификация очков XREAL. Русский заменяет польский язык, английский сохраняется. EXE и BIN скачиваются отдельно; установка Python не нужна.

**Актуальный выпуск: 0.7.0.** One Pro — проверенная пользователем сборка с AI HDR, режимами «Чтение» и «Кино» и двумя отдельными строками Real3D. Для обычного One подготовлен экспериментальный порт. Для 1S — только перевод штатной Pilot 1.9.1.

## Как установить

1. Скачайте EXE и подходящий BIN из таблицы. EXE запускается сразу, установки в систему не требует.
2. Закройте страницу обновления XREAL и другие обновляторы. Подключите очки кабелем с передачей данных. Для самой прошивки видеовыход USB-C не нужен.
3. Запустите EXE, нажмите «Обновить список» и выберите свои очки.
4. Нажмите «Выбрать BIN…», выберите скачанный файл и прочитайте описание модели.
5. Нажмите «Установить выбранную прошивку». Не отключайте кабель до завершения передачи и проверки файлов.
6. После сообщения об успехе подключите очки к источнику видео. В языковом меню выберите русский на месте польского.

EXE не подписан цифровой подписью. Windows может показать предупреждение об издателе. Сверяйте источник скачивания и SHA256 с этим выпуском.

Требуемая SoC: `15.1.03.603_20260914`. Для One / One Pro допустимы Pilot `1.9.1.20260914175625` и `2.0.0.20260920102250`; для 1S — только `1.9.1.20260914175625`. Если версии отличаются, отправьте отчёт диагностики: установщик не обходит проверки совместимости.

## Если появилась ошибка

Откройте **«Диагностика / отчёт об ошибке…»**. Там видны код ошибки, её текст, этап установки, версия приложения и хеш выбранного BIN. Кнопка **«Проверить сейчас»** читает USB-модель, SKU, версии SoC/Pilot и при выбранном BIN проверяет совместимость. Она работает и без BIN; при отсутствии очков объяснит, что устройство не найдено.

Нажмите **«Скопировать отчёт»** и отправьте текст автору или приложите его к [issue](https://github.com/Skiters/xreal-one-pro-russian/issues). Можно сохранить TXT. Отчёт открыт для просмотра, не зашифрован, не содержит серийного номера, имени компьютера или локальных путей. Приложение ничего автоматически не отправляет в интернет. Короткий код указывает этап, а полный текст позволяет понять причину — присылайте весь отчёт.

Примеры: `XR-DIAGNOSTIC-NO-DEVICE` — очки не найдены; `XR-DIAGNOSTIC-ABI` — отличаются системные библиотеки или видеопамять; `XR-UPDATE-TRANSFER` — сбой передачи. После установки текст для поддержки также сохраняется в `%LOCALAPPDATA%\XREAL-Russian-Updater\support-report.txt`.

Если передача завершилась, но проверка файлов прервалась, переподключите очки и нажмите **«Проверить без записи»** с тем же BIN. Это проверка уже установленных файлов, а не повторная прошивка. Автоматического отката или повторения записи нет.

## Что реализовано

- Согласованный русский шрифт и перевод меню; английский остаётся доступен.
- One Pro: отдельные строки «Real3D One Pro» и «Real3D Pro+», штатная регулировка глубины сохранена. Оба варианта используют оценку глубины Pilot 2.0; различается обработчик построения стереокадра. Это сравнение алгоритмов, а не две установленные прошивки.
- One Pro / экспериментальный One: CPU-пути AI HDR, «Чтение», «Кино», Real3D; полный цветовой 3D LUT, векторизация и постоянные рабочие потоки. Наличие режима не означает подтверждённые 60 обработанных кадров/с.
- One Pro: профиль Hebe/Gina с пределом `luminance` 500. Это значение настройки, **не измерение яркости в нитах**. Для One этот профиль не применяется.
- 1S: заменены таблица перевода, два файла шрифтов и встроенные шрифтовые ресурсы OSD. Драйверы, остальные исполняемые файлы и конфигурации оставлены побайтно штатными. Заводские функции 1S сохраняются.
- EXE: прокрутка при небольшом окне/высоком масштабе Windows, проверки модели и содержимого BIN, чтение установленных файлов обратно, доступный отчёт диагностики.

По [официальным спецификациям XREAL](https://tutorials.xreal.com/docs/glasses/one-series/spec/), One и One Pro используют X1, но имеют разные панели. Совпадение чипа не доказывает совместимость всего программного стека: официальный DSP у One отличается от One Pro. Поэтому установщик проверяет библиотеки и карту памяти до записи Pilot 2.0. Несовпадение останавливает установку; обходить его не нужно.

Сборки меняют компонент Pilot. MCU, системная SoC, DSP и калибровки не перепрошиваются. Разгон 133/240 Гц и изменение EDID в этот выпуск не входят. На One Pro опубликован **тот же BIN rc7**, который проверил пользователь; его внутренний номер сборки остаётся `0.7.0-rc7`. Версия общего выпуска и нового установщика — `0.7.0`.
