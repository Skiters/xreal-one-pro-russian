# Русское меню для XREAL One и One Pro

Неофициальный Windows-обновлятор. Русский язык занимает место польского, английский остаётся. Для установки нужны **два скачанных файла**: приложение EXE и один BIN для вашей модели.

[отдельный тестовый релиз v0.6.0](https://github.com/Skiters/xreal-one-pro-russian/releases/tag/v0.6.0-one-test).
Нужны новый `XREAL-Russian-Updater-v0.6.0-test.exe` и
`XREAL-One-Pilot2-RU-Real3D-AIHDR-TEST.bin`. **На обычном One физически ещё не проверено.**
Внутри русский Pilot 2.0, CPU-порт Real3D и AI HDR, настройки панели One без Hebe и разгона.
[Описание и порядок проверки](installer/ONE-TEST.md). Обычные варианты ниже доступны отдельно.

Официальные Pilot 1.9.1 для One и One Pro побайтно совпадают, поэтому стандартный русский BIN общий. Он проверен на One Pro X1112010; **на обычном One физическая установка ещё не проверена**. Экспериментальный BIN предназначен только для One Pro X1112010. На проверенном устройстве Real3D даёт небольшую глубину и около 53–55 обработанных кадров/с; стабильные 60 не подтверждены. Заявленные в прошивке 240 Гц не подтверждены измерением дисплея.

## Установка

1. Скачайте EXE и **один** подходящий BIN из таблицы. Распаковывать или переименовывать файлы не нужно. Закройте страницу обновления XREAL и другие запущенные обновляторы.
2. Подключите очки к USB компьютера кабелем с передачей данных. Запустите EXE, нажмите «Обновить список» и выберите очки.
3. Нажмите «Выбрать BIN…» и укажите скачанный файл. Проверьте описание варианта в окне, затем нажмите «Установить выбранную прошивку».
4. Не отключайте кабель до сообщения «Готово. Файлы проверены». Подключите очки к источнику видео; русский находится на месте польского в меню языков.

Приложение **до записи** проверяет SHA256 BIN, USB-модель, SoC, текущую версию Pilot и SKU. Если устройство не подходит, установка останавливается. Поддерживаемый SoC: `15.1.03.603_20260914`; исходные версии Pilot: `1.9.1.20260914175625` и `2.0.0.20260920102250`. Для обычного One стандартный BIN требует исходную Pilot 1.9.1. Программа не обновляет отдельно MCU или DSP.

Если пакет принят, но проверка прервалась, переподключите очки и нажмите «Проверить без записи» с тем же BIN. Журнал ошибки: `%LOCALAPPDATA%\XREAL-Russian-Updater\last-error.txt`.

Это обновление компонента **Pilot**, не полный резервный образ очков. Прерывание записи может нарушить их работу. EXE не подписан сертификатом издателя. Проект не связан с XREAL; права на исходные компоненты и шрифты принадлежат их правообладателям.
