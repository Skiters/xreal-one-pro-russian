# XREAL One Pro — русское меню и Windows-установщик

Неофициальный проект с двумя прошивками в одном переносимом EXE для Windows 10/11 x64. Приложение показывает подключённые очки, позволяет выбрать вариант и записывает его через USB по протоколу сайта XREAL. Обе прошивки содержатся в EXE; после скачивания интернет не нужен. Русский занимает место польского, английский остаётся доступен.

## Скачать

**[XREAL-Russian-Updater.exe — v0.3.0](https://github.com/Skiters/xreal-one-pro-russian/releases/tag/v0.3.0-windows)**

На странице выпуска находится EXE и его SHA256. Файл запускается без Python и отдельной распаковки прошивок. Windows может предупредить о неподписанном издателе.

## Выбор прошивки

| Вариант | Что включено | Совместимость и статус |
| --- | --- | --- |
| **Обычная русская · Pilot 1.9.1** | Перевод 437 строк; согласованные кириллические и латинские шрифты. Поведение изображения — как у обычной Pilot 1.9.1. | One Pro `X1112010` и `X1112011`. Проверена на `X1112010`; для `X1112011` подтверждение установки пока ожидается. |
| **Экспериментальная One Pro+ · Pilot 2.0** | Адаптация прошивки Pro+ для One Pro: русский интерфейс, AI HDR с обработкой изображения, работающие режимы «Чтение» и «Кино», профиль яркости Hebe в пределах `luminance = 500`. | Только One Pro `X1112010`. На одном устройстве пользователь подтвердил изображение, работу режимов и заметную прибавку яркости. Фактические ниты не измерялись. |

В обоих вариантах единый шрифт меню. Экспериментальная сборка включает настройки 240 Гц из Pilot 2.0, но работа дисплея на 240 Гц не подтверждена измерением и не обещается установщиком. Она отличается от официальной прошивки Pro+ и предназначена только для указанного One Pro. Попытка установить `luminance = 1200` была откатана: драйвер отклонял команды выше 500; опубликованный вариант остаётся в допустимом диапазоне и прошёл проверку журнала без ошибок управления яркостью.

## Установка

1. Скачайте EXE, закройте страницу обновления XREAL и старые экземпляры установщика.
2. Подключите очки к компьютеру кабелем USB с передачей данных. Видеовыход на компьютере для прошивки не требуется.
3. Нажмите «Обновить список», выберите очки и одну из двух прошивок. Описание выбранного варианта отображается прямо в окне.
4. Нажмите «Установить выбранную прошивку». Не отсоединяйте очки до сообщения «Готово. Файлы проверены».
5. Подключите очки к источнику видео. Русский язык находится на месте польского в меню языков. Для экспериментальной сборки проверьте SDR, AI HDR, «Чтение» и «Кино».

Для возврата на обычный вариант выберите его в том же приложении и выполните установку. Возможность переключения между Pilot 1.9.1 и Pilot 2.0 проверена автоматическим тестом протокола; физическая установка обычного варианта поверх Pilot 2.0 на другом устройстве пока не подтверждена. Перед записью приложение сверяет USB-устройство, SoC, текущую версию Pilot и SKU. Поддерживаемый SoC: `15.1.03.603_20260914`; исходные версии Pilot: `1.9.1.20260914175625` и `2.0.0.20260920102250`. Другие модели и версии блокируются до записи.

Кнопка «Проверить без записи» сравнивает файлы на очках с **выбранной** прошивкой. Если связь прервалась уже после принятия пакета, переподключите очки и используйте эту кнопку. Повторная запись автоматически не запускается.

## Что изменилось в шрифтах

- В каждом из **15 встроенных стилей** пересобраны **166 символов**: русский алфавит, латиница ASCII, цифры и нужная пунктуация.
- Кириллица и латиница одного стиля рисуются одним шрифтом из семейства MiSans Latin. Два внешних TTF согласованы с тем же источником.
- Высоты строк сохранены. Для самого тесного стиля размер и вертикальное положение подобраны так, чтобы помещались диакритика и нижние части букв.
- Исходные значки и символы других языков остаются доступны через исходные наборы. Английские тексты не изменены; их начертание обновлено вместе с русским.
- Размеры заголовков и обычного текста по-прежнему отличаются по назначению.

[Предпросмотр всех стилей](outputs/xreal-russian-firmware/font-preview.png) показывает реальные растры новой сборки, а не фотографию экрана очков.

## Возможности Windows-приложения

Выбор устройства, проверка совместимости и целостности пакета, индикатор прогресса, ожидание перезапуска, проверка записанных файлов и восстановление соединения для повторного чтения. Интерфейс учитывает размер экрана и масштаб Windows, переносит текст и поддерживает прокрутку колесом, полосами и переходом Tab.

## Решение проблем

| Ситуация | Что делать |
| --- | --- |
| Очки отсутствуют в списке | Проверьте USB-порт и кабель с передачей данных, нажмите «Обновить список». |
| Версия не поддерживается | Сверьте SoC, Pilot и SKU с разделом «Установка» и выберите подходящий вариант. |
| Пакет принят, проверка не завершена | После сообщения об ошибке переподключите очки и нажмите «Проверить без записи». |
| Сбой во время передачи | Сохраните текст ошибки и журнал; не считайте установку завершённой. |
| Нижние элементы не видны | Прокрутите колесом, полосой прокрутки или перейдите к кнопке клавишей Tab. |
| Ошибка `1025/513` в старом EXE | Загрузите актуальный выпуск: обработка размера USB-отчёта исправлена. |

Журнал ошибки: `%LOCALAPPDATA%\XREAL-Russian-Updater\last-error.txt`.

[Сообщить о проблеме](https://github.com/Skiters/xreal-one-pro-russian/issues): укажите версию приложения, версии очков, этап сбоя и текст ошибки. Проверьте журнал на личные данные перед публикацией.

## Проверки и ограничения

Обе прошивки установлены и проверены пользователем на конкретном XREAL One Pro `X1112010`. Для экспериментальной сборки подтверждены SDR, AI HDR, «Чтение», «Кино» и заметная прибавка видимой яркости. Это не измерение пиковой яркости и не гарантия для других устройств.

Для новых шрифтов обычной версии выполнены **2490 проверок получения символов**, **2460 проверок растров** и **75 проверок исходных резервных символов** штатными ARM64-функциями в эмуляторе. Для внешних TTF проверены **332 пары контуров и метрик**. Экспериментальная Pilot 2.0 содержит дополнительный обработчик изображения; её работу оценивали на устройстве.

Автоматические тесты проверяют оба встроенных пакета, ограничения по SKU, переключение версий и интерфейс при 100%, 150% и 200% масштабе. Полный автоматический обход всех меню и измерение ширины каждой подписи не выполнялись.

**Неофициальная экспериментальная модификация.** Полный резервный образ не создаётся. Прерывание записи может нарушить работу очков. EXE не подписан сертификатом издателя, поэтому Windows может показать предупреждение об неизвестном издателе.

Для пересборки самих прошивок нужны локальные исходные архивы XREAL, оригинальные библиотеки и шрифты; полный цикл с чистого клона пока не автоматизирован. Старые скрипты `build_russian_pilot.py` и `patch_embedded_fonts.py` сохранены для истории предыдущего способа подстановки.

SHA256 пакетов:

```text
258ecdb3a9892c7a2bf700c4f0fbccf52ced8915081c0109beb08c59c60418ec
2230136051f41b5cf7a753ea47b51b502df1fb743f5049a8c9443fb9f99499c3
```

Это обновление компонента **Pilot**, а не полный образ памяти. Контрольная сумма EXE находится в `SHA256SUMS.txt` на странице выпуска. Резервные копии, сырые журналы и браузерный кэш не публикуются. Проект не связан с XREAL; права на исходные компоненты и сторонние шрифты остаются у правообладателей.
