# Экспериментальная Pilot 2.0 с Real3D

Пакет `XREAL-Pilot2-RU-Hebe-Real3D-CPU.bin` предназначен только для XREAL One Pro SKU `X1112010`, SoC `15.1.03.603_20260914`. SHA256:

```text
1b72fc6acd90fc9b8995644cca659907d571292f19a19a33cdbddd59da5decd0
```

Он основан на [Pilot 2.0 с профилем Hebe](../xreal-pilot2-hebe/README.md) и добавляет CPU-обработку Real3D вместо несовместимого DSP-вызова. На одном устройстве установку подтвердили чтением восьми файлов обратно; пользователь увидел обычную картинку и небольшую глубину в Real3D. По журналам обработка идёт примерно с 53–55 кадрами/с при видеовходе 60 Гц. Целевые 60 обработанных кадров/с пока не подтверждены. Исходник CPU-обработки и [сравнение оригинальных прошивок](../../work/3d-lab/vendor_comparison.md) опубликованы отдельно.

Для установки используйте [Windows-приложение](../../installer/README.md) и выберите этот BIN-файл. Приложение проверяет SKU, версии и целостность пакета до записи. В ZIP также находится русская Pilot 1.9.1 без Real3D; переход обратно на неё проверен автоматическим тестом протокола, но после Pilot 2.0 физически не подтверждён на другом устройстве.
