# Входной контейнер для сборки адаптера

`XREAL-Pilot2-RU-Hebe-Real3D-CPU.bin` хранится здесь как закреплённый вход для `firmware/build.py`, а не как рекомендуемый файл установки. SHA256: `1b72fc6acd90fc9b8995644cca659907d571292f19a19a33cdbddd59da5decd0`.

Актуальные готовые прошивки, поддерживаемые модели и инструкции: [README проекта](../../README.md). Для установки выбирайте BIN из текущего релиза. Этот исходный контейнер нужен для воспроизводимой сборки и проверки неизменности входов.
