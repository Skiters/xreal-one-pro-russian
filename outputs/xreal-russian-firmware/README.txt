Русификация Pilot 1.9.1 для One / One Pro

Русский заменяет польский, английский сохранён. Начертания встроенного и внешнего шрифтов согласованы. Этот файл служит проверенным источником языковых ресурсов для сборки 1S и дополнительным вариантом только с переводом для One / One Pro.

Готовый файл XREAL-One-OnePro-RU-Pilot1.9.1.bin и общий EXE находятся в выпуске 0.7.0:
https://github.com/Skiters/xreal-one-pro-russian/releases/tag/v0.7.0

Для 1S нужен отдельный BIN 1S. Совместимость и установка описаны в основном README проекта.
