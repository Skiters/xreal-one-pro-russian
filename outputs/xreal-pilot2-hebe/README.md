# Экспериментальная Pilot 2.0 для One Pro

Файл `XREAL-Pilot2-RU-Hebe-Within-Limit.bin` предназначен только для XREAL One Pro `X1112010` с SoC `15.1.03.603_20260914`. Внутри переносимого Windows-установщика он доступен как «Экспериментальная One Pro+ · Pilot 2.0». Исходный контейнер: Pilot `2.0.0.20260920102250` для семейства Pro+.

Сборка содержит русское меню вместо польского, единые шрифты, CPU-обработку AI HDR, исправленные RGB-настройки режимов «Чтение» и «Кино», а также профиль яркости Hebe для One Pro. Максимальное управляющее значение `luminance_data` для AI HDR — **500**. Значение 1200 в этот распространяемый пакет не входит: на испытанном устройстве команды выше 500 отклонялись драйвером.

Пакет записан на одном One Pro `X1112010`, контрольные файлы считаны обратно. Пользователь подтвердил изображение в SDR и AI HDR, работу «Чтения» и «Кино» и видимую прибавку яркости. После установки этого варианта свежий журнал показал успешные команды яркости в диапазоне 0–500 без ошибок. Фактическая яркость в нитах не измерялась. Работа 240 Гц, иных SKU и других версий SoC не подтверждена.

SHA256 контейнера:

```text

```
