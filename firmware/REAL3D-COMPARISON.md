# Два алгоритма Real3D в выпуске 0.7.0

В BIN для One Pro X1112010 доступны две отдельные строки меню: **Real3D One Pro** и **Real3D Pro+**. Регулировка глубины остаётся самостоятельной настройкой с четырьмя штатными уровнями.

Оба режима работают внутри Pilot 2.0 и используют её оценку глубины. One Pro вызывает штатный CPU mesh из библиотеки One Pro; Pro+ использует наш CPU-порт обработки карты смещений. Выбор One Pro не переключает всю прошивку обратно на Pilot 1.9.1. Точного воспроизведения закрытого DSP-алгоритма Pro+ этот порт не заявляет.

## Реализация

- `compare_ui.c`, `ui_dispatch.S`, `generate_compare_ui.py`, `compare_modes.py` добавляют отдельную строку меню и обработчики. Раскладка обновляется после регистрации и выбора режима, включая случай скрытого пункта SBS.
- `onepro_warp.c` согласует смещение двух глаз: каждая сторона получает половину полной диспаратности. Это устраняет удвоение сдвига при использовании симметричного mesh.
- `work/3d-lab/real3d_cpu.c` обрабатывает карту Q2/Q3/Q4; сдвиг цветовых плоскостей I420 вдвое меньше сдвига яркости.
- Для legacy mesh дополнительно проверяется системная `libdl-2.25.so`. Сравнительный вариант разрешён только для One Pro; обычный One получает Pro+ CPU-порт без этого mesh.

## Проверка

В опубликованный BIN One Pro скопирована проверенная пользователем сборка с внутренней версией `0.7.0-rc7`. SHA256: `721e08d0828e116ad18d26168d43a5fc9788ba3ce52e0b34a7c234159b5bde43`. После установки все 71 файла считаны обратно; пользователь подтвердил нормальную работу. ARM64-проверки интерфейса, полного кадра mesh и LUT пройдены. Измерений стабильных 60 обработанных кадров/с и задержки через оптику для этого выпуска нет.

## Сборка

`firmware/build.py --compare-onepro-warp` собирает вариант One Pro с двумя строками. Нужны закреплённые Clang/sysroot и vendor-входы; параметры перечислены в [описании сборки](README.md). Флаг несовместим с `--capture-real3d`: legacy mesh меняет исходное изображение.

Воспроизведение с текущими метаданными создаёт новый BIN; его нельзя считать побайтно тем же проверенным файлом. Для установки используйте [файлы выпуска](../README.md).
