# XREAL Russian Updater v0.3.0

Переносимое приложение Windows 10/11 x64. Содержит две прошивки: обычную русскую Pilot 1.9.1 и экспериментальную русскую Pilot 2.0 с AI HDR, режимами «Чтение»/«Кино» и профилем Hebe. [Инструкция установки и совместимость](../README.md).

Обычный вариант допускает SKU `X1112010` и `X1112011`. Экспериментальный допускает только проверенный на устройстве `X1112010`. Приложение принимает исходные версии Pilot 1.9.1 и 2.0.0 при точном совпадении SoC; после записи проверяет выбранную версию. [Обоснование второго SKU](compatibility.md).

## Использование

1. Запустите EXE и подключите очки. Закройте другие обновляторы.
2. Нажмите «Обновить список», выберите устройство и вариант прошивки.
3. Нажмите «3. Установить выбранную прошивку» и дождитесь сообщения «Готово. Файлы проверены».
4. Для уже установленного варианта используйте «Проверить без записи».

Интерфейс поддерживает масштаб Windows, изменение размеров окна и прокрутку. Установка не начинается автоматически при запуске или выборе устройства.

## Как работает

Проверяются SHA256 обоих встроенных пакетов и совместимость выбранного варианта с моделью/версиями. Используется HID-протокол веб-обновлятора: 4628 — заголовок, 4629 — последовательные блоки до 490 байт, 4630 — применение. Проверяются CRC, команда и статус ответа. Дополнение HID-отчёта Windows учитывается.

После принятия пакета приложение ждёт перезапуска и сравнивает пять файлов обычного варианта или девять файлов экспериментального. При разрыве соединения повторяется только чтение целиком с новым соединением, до трёх попыток. Отдельные блоки записи автоматически не повторяются. Обновлятор не переключается на другое устройство. Полный резервный образ не создаётся.

Диагностика ошибок: `%LOCALAPPDATA%/XREAL-Russian-Updater/last-error.txt`. EXE не подписан сертификатом издателя.

## Сборка

На Windows x64 с Python 3.13 из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File installer/build.ps1
```

Скрипт создаёт окружение в `work/installer-venv`, устанавливает зависимости, выполняет тесты и собирает EXE в `outputs/xreal-windows-installer/`. Пакеты берутся из `outputs/xreal-russian-firmware/` и `outputs/xreal-pilot2-hebe/`. Упаковка — PyInstaller one-file.

## Диагностика сборки

```text
XREAL-Russian-Updater.exe --self-test report.json
XREAL-Russian-Updater.exe --check-device report.json
XREAL-Russian-Updater.exe --verify-device report.json --firmware experimental
```

Первый режим проверяет оба пакета и загрузку интерфейса, только перечисляя USB-устройства. Второй читает модель и версии. Третий дополнительно проверяет установленные файлы. Последние два требуют ровно одни подключённые очки. Ни один из этих режимов не записывает прошивку.

Автоматические тесты проверяют протокол, несовместимое устройство, частичную передачу, ошибки чтения, восстановление соединения без повторной прошивки и доступность элементов на маленьком окне при разных DPI. Они не заменяют визуальную проверку в очках.
