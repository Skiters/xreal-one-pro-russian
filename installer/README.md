# XREAL Russian Updater v0.5.0

Переносимое приложение Windows 10/11 x64. EXE и два русских BIN лежат отдельными файлами в ZIP. Приложение позволяет выбрать BIN с диска; оно принимает только файлы с проверенными SHA256 этого выпуска. [Инструкция установки и совместимость](../README.md).

Pilot 1.9.1 предназначен для One (USB PID `0438`) и One Pro (USB PID `0436`, SKU `X1112010`/`X1112011`); официальный Pilot для обеих моделей совпадает по MD5. Экспериментальный Pilot 2.0 допускает только One Pro `X1112010`. Приложение принимает поддерживаемые исходные версии при точном совпадении SoC; после записи проверяет выбранную версию. [Обоснование второго SKU One Pro](compatibility.md).

## Использование

1. Запустите EXE и подключите очки. Закройте другие обновляторы.
2. Нажмите «Обновить список», выберите устройство, затем «Выбрать BIN…» и файл прошивки из ZIP.
3. Нажмите «3. Установить выбранную прошивку» и дождитесь сообщения «Готово. Файлы проверены».
4. Для уже установленного варианта используйте «Проверить без записи».

Интерфейс поддерживает масштаб Windows, изменение размеров окна и прокрутку. Установка не начинается автоматически при запуске или выборе устройства.

## Как работает

Проверяются SHA256 выбранного BIN и совместимость с моделью/версиями. Используется HID-протокол веб-обновлятора: 4628 — заголовок, 4629 — последовательные блоки до 490 байт, 4630 — применение. Проверяются CRC, команда и статус ответа. Дополнение HID-отчёта Windows учитывается.

После принятия пакета приложение ждёт перезапуска и сравнивает пять файлов обычного варианта или девять файлов экспериментального. При разрыве соединения повторяется только чтение целиком с новым соединением, до трёх попыток. Отдельные блоки записи автоматически не повторяются. Обновлятор не переключается на другое устройство. Полный резервный образ не создаётся.

Диагностика ошибок: `%LOCALAPPDATA%/XREAL-Russian-Updater/last-error.txt`. EXE не подписан сертификатом издателя.

## Сборка

На Windows x64 с Python 3.13 из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File installer/build.ps1
```

Скрипт создаёт окружение в `work/installer-venv`, устанавливает зависимости, выполняет тесты, собирает EXE и ZIP в `outputs/xreal-windows-installer/`. Два BIN копируются из `outputs/xreal-russian-firmware/` и `outputs/xreal-pilot2-real3d-cpu/`. Упаковка EXE — PyInstaller one-file; BIN в него не встраиваются.

## Диагностика сборки

```text
XREAL-Russian-Updater.exe --self-test report.json
XREAL-Russian-Updater.exe --check-device report.json
XREAL-Russian-Updater.exe --verify-device report.json --firmware experimental
```

Первый режим проверяет оба BIN рядом с EXE и загрузку интерфейса, только перечисляя USB-устройства. Второй читает модель и версии. Третий дополнительно проверяет установленные файлы. Последние два требуют ровно одни подключённые очки. Ни один из этих режимов не записывает прошивку.

Автоматические тесты проверяют протокол, несовместимое устройство, частичную передачу, ошибки чтения, восстановление соединения без повторной прошивки и доступность элементов на маленьком окне при разных DPI. Они не заменяют визуальную проверку в очках.
