# XREAL Russian Updater v0.2.1

Переносимое приложение Windows 10/11 x64. Содержит русскую прошивку с едиными шрифтами, проверенную пользователем на XREAL One Pro. [Инструкция установки и совместимость](../README.md).

В v0.2.1 разрешены SKU `X1112010` и `X1112011` при прежних строгих проверках USB-модели, SoC и Pilot. Пакет не изменён; физическая проверка на `X1112011` ещё ожидается. [Обоснование](compatibility.md).

## Использование

1. Запустите EXE и подключите очки. Закройте другие обновляторы.
2. Нажмите «Обновить список» и выберите устройство.
3. Нажмите «2. Установить прошивку» и дождитесь сообщения «Готово. Файлы проверены».
4. Для уже установленного пакета используйте «Проверить без записи».

Интерфейс поддерживает масштаб Windows, изменение размеров окна и прокрутку. Установка не начинается автоматически при запуске или выборе устройства.

## Как работает

Проверяется закреплённая SHA256 пакета и совместимость модели/версий. Используется HID-протокол веб-обновлятора: 4628 — заголовок, 4629 — последовательные блоки до 490 байт, 4630 — применение. Проверяются CRC, команда и статус ответа. Дополнение HID-отчёта Windows учитывается.

После принятия пакета приложение ждёт перезапуска и сравнивает пять файлов с прошивкой. При разрыве соединения повторяется только чтение целиком с новым соединением, до трёх попыток. Отдельные блоки записи автоматически не повторяются. Обновлятор не переключается на другое устройство. Полный резервный образ не создаётся.

Диагностика ошибок: `%LOCALAPPDATA%/XREAL-Russian-Updater/last-error.txt`. EXE не подписан сертификатом издателя.

## Сборка

На Windows x64 с Python 3.13 из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File installer/build.ps1
```

Скрипт создаёт окружение в `work/installer-venv`, устанавливает зависимости, выполняет тесты и собирает EXE в `outputs/xreal-windows-installer/`. Встроенный пакет берётся из `outputs/xreal-russian-firmware/`. Упаковка — PyInstaller one-file.

## Диагностика сборки

```text
XREAL-Russian-Updater.exe --self-test report.json
XREAL-Russian-Updater.exe --check-device report.json
XREAL-Russian-Updater.exe --verify-device report.json
```

Первый режим проверяет пакет и загрузку интерфейса, только перечисляя USB-устройства. Второй читает модель и версии. Третий дополнительно проверяет установленные файлы. Последние два требуют ровно одни подключённые очки. Ни один из этих режимов не записывает прошивку.

Автоматические тесты проверяют протокол, несовместимое устройство, частичную передачу, ошибки чтения, восстановление соединения без повторной прошивки и доступность элементов на маленьком окне при разных DPI. Они не заменяют визуальную проверку в очках.
