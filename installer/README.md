# Windows-приложение

Версия 0.1.3 адаптирует начальные размеры к рабочей области экрана и масштабу Windows. Окно можно уменьшать; текст переносится по доступной ширине. Доступны вертикальная прокрутка колесом мыши и полосой прокрутки, прокрутка к кнопке при переходе Tab; на очень узком окне появляется горизонтальная полоса. Проверена доступность нижних элементов в окне 420×280 при 96, 144 и 192 DPI.

Версия 0.1.2 ждёт перезапуска после приёма пакета и при разрыве USB повторяет только чтение файлов (до трёх попыток с новым соединением). Добавлена кнопка «Проверить без записи» для проверки уже установленного пакета. Ни одна ошибка чтения не запускает повторную прошивку. Ошибки самого транспорта содержат номер команды и сообщение HIDAPI; ошибка завершения чтения не скрывает исходную причину.

Версия 0.1.1 исправляет ошибку `Incomplete HID write: 1025/513`: Windows HIDAPI дополняет короткий выходной отчёт нулями и возвращает его полный размер. Ответ устройства по-прежнему проверяется по команде, CRC и статусу. [Описание поведения HIDAPI](https://github.com/libusb/hidapi/wiki/Known-Issues).

`XREAL-Russian-Updater.exe` — переносимое приложение для Windows 10/11 x64. Установка Python, ручная распаковка и выбор файла прошивки не нужны. Пакет прошивки встроен, работа офлайн. Это неофициальный экспериментальный инструмент.

1. Запустите EXE, подключите XREAL One Pro кабелем с передачей данных. Закройте веб-обновлятор XREAL.
2. Нажмите «Обновить список» и выберите очки.
3. Нажмите «Установить русскую прошивку». Дождитесь сообщения «Готово. Файлы проверены».
4. Отключите очки, подключите источник видео и проверьте русское меню (вместо польского).

Приложение принимает только SoC `15.1.03.603_20260914`, Pilot `1.9.1.20260914175625`, SKU `X1112010`. Другие версии отклоняются до записи. Полный резервный образ не создаётся. Во время установки нельзя отключать питание/USB.

Пакет проверяется по закреплённой SHA256, затем передаётся через HID: команды 4628 (64-байтовый заголовок), 4629 (последовательные блоки до 490 байт), 4630 (применение). Проверяются ответы и CRC кадров. Автоматического повтора записи после ошибки нет. После перезапуска проверяются хеши пяти файлов, считанных с выбранного устройства. Обновлятор не переключается на другие подключённые очки.

При ошибке успех не показывается; диагностический журнал сохраняется локально в `%LOCALAPPDATA%/XREAL-Russian-Updater/last-error.txt`. Сертификата подписи кода у проекта нет: Windows может показывать предупреждение о неизвестном издателе.

## Сборка

На Windows x64 с Python 3.13: `powershell -ExecutionPolicy Bypass -File installer/build.ps1`. Скрипт создаёт локальное окружение, устанавливает зависимости, выполняет тесты и собирает EXE в `outputs/xreal-windows-installer/`. Входной готовый пакет берётся из репозитория. Используется [PyInstaller one-file](https://pyinstaller.org/en/stable/usage.html).

`XREAL-Russian-Updater.exe --self-test report.json` проверяет встроенный пакет, загрузку интерфейса и перечисление HID, не открывая устройства и не выполняя запись.

Тесты с имитатором устройства проверяют выбор, последовательность команд, блокировку несовместимой версии, отказ передачи без повторов и ошибки чтения обратно. Они не заменяют испытание самого EXE на физических очках.
