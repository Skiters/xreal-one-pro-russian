## Официальные входы, проверенные 21 октября 2026

[Веб-обновлятор XREAL](https://www.xreal.com/ota/) сопоставляет One Pro с hardwareCode 6, One с 7, 1S с 9. У 1S загрузчик имеет PID 043d, рабочий режим — 043e. Обновлятор проекта работает только с рабочим режимом.

Публичный API: `https://app-api.xreal.com/api/nebula/v1/isc/device/package?packageName=ai.nreal.web&hardwareCode=9&versionCode=1` (для One заменить 9 на 7).

- [Штатный Pilot 1S](https://media.xreal.com/nebula-prod/web/hardware_up/5a136461-fa17-4b16-a319-2b698ad8d272.bin).
- [Штатный Pilot One](https://media.xreal.com/nebula-prod/web/hardware_up/d76f2579-4ffa-40e6-a232-dc1e5f5cf85a.bin).
- Оба файла побайтно одинаковы: SHA256 `bc467c9c361a131ffe3dfd9b42f139ff9f675de40bd88b41b58c2d30d8d7e621`, MD5 `11c30c6197fbe18ce7591f4d7bd6993d`. Все 73 записи ZIP совпали с исходной Pilot One Pro, на которой подготовлен перевод. Это относится к Pilot, не ко всей системной прошивке.
- По API DSP One — `15.A.00.069_20241211`; One Pro / 1S — `15.A.01.097_20250430`. Этот выпуск DSP не заменяет.

[Спецификация](https://tutorials.xreal.com/docs/glasses/one-series/spec/) указывает X1 у One и One Pro, но разные OLED-панели. One получает собственный GF, без профиля яркости Hebe. 1S сохраняет все заводские конфигурации и разрешение.

В 1S BIN добавлена проверяемая метка модели. Он отвергается на One / One Pro и наоборот. Русификация 1S переносит только четыре ресурса из проверенного перевода: CSV, два TTF и libnr_osd.so со встроенным шрифтом. Проверка совпадения всего штатного Pilot обязательна в build_1s.py; остальные файлы должны остаться неизменными.

One Pro rc7 прошёл чтение всех 71 файлов после установки; пользователь подтвердил нормальную работу. Для One и 1S проверки упаковки не заменяют испытаний на очках.
