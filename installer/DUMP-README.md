# XREAL Dump 0.1 — Windows x64

Собираем дампы следующих моделей. Названия сверены с карточками каталога 20 ноября 2026 года. Для всех используется один сборщик. По отчётам владельцев проверяем доступность USB-экспорта, состав прошивок и различия библиотек и моделей. Для XREAL 1 Pro+ особенно интересуют компоненты AI HDR и Real3D.

- [XREAL Air](https://xreal.com.ru/products/air)
- [XREAL Air 2](https://xreal.com.ru/products/air-2)
- [XREAL Air 2 Pro](https://xreal.com.ru/products/air-2-pro)
- [XREAL Air 2 Ultra](https://xreal.com.ru/products/air-2-ultra)
- [ROG XREAL R1](https://xreal.com.ru/products/rog-xreal-r1)
- [XREAL XBX a01](https://xreal.com.ru/products/xbx-a01)
- [XREAL Aura](https://xreal.com.ru/products/aura)

[Скачать сборщик для Windows x64 (ZIP)](https://raw.githubusercontent.com/Skiters/xreal-one-pro-russian/feat/russian-menu-font-fix/installer/XREAL-Dump-0.1-Windows.zip). Распакуйте ZIP. SHA256 архива — `6c4583577e4d327f5394c859bd0e9047195d25043e563ce2d59d630eed959d49`.

**Как передать результат.** [Откройте заявку в проекте](https://github.com/Skiters/xreal-one-pro-russian/issues/new). В заголовке укажите модель и версию Pilot, если она известна. В сообщении напишите, штатная ли прошивка, увидел ли сборщик очки и завершилось ли чтение. Если хотите поделиться дампом, приложите ZIP с проверенными вами файлами или ссылку на него. Заявки публичны. Можно прислать только проверенный `report.json`, убрав личные данные, или просто описать ошибку обнаружения. Серийный номер не нужен.

Запустите XREAL-Dump-0.1.exe, подключите очки кабелем передачи данных,
выберите устройство и нажмите «Собрать дамп». Выберите папку сохранения.
Другие приложения, обращающиеся к очкам, предварительно закройте.

Сборщик не прошивает устройство, не перезагружает его и не отправляет данные
в интернет. Остановка выполняется между запросами; отдельное чтение может
длиться несколько минут. После остановки полученные файлы сохраняются.

Результат: report.json, исходные ZIP-ответы и распакованные файлы в files/.
Отчёт связывает каждую папку с запрошенным путём, содержит ошибки и SHA256.
Перед отправкой владельцу проекта проверьте содержимое: настройки и модели
могут содержать идентификаторы или другую информацию устройства. Затем
упакуйте всю папку результата через Windows «Сжать в ZIP-файл».

Это файловый сбор, а не полный образ flash. Обнаруживаются XREAL VID 3318
с vendor HID интерфейсом 0; новые PID не исключаются. Поддержка конкретного
устройства, в том числе Pro+, зависит от реализации протокола. ANX и другие
бренды с иным VID/протоколом не поддерживаются автоматически. Android ADB,
разделы загрузчика и защищённые разделы в этой версии не читаются.

Сборщик пробует каталоги прошивок и библиотек и перечисленные системные
пути. Если устройство отказывает в экспорте каталога, сканировать его
рекурсивно невозможно. Список Pilot расширяется из checksums.sha256.
Названия .rknn не предполагаются обязательными для платформы XREAL.
Ответ ограничен 64 МиБ, распаковка ответа — 256 МиБ; суммарная передача —
1 ГиБ. В отчёте full_dump всегда false: полнота файловой системы не доказана.

Сборка: существующий Python installer-venv, PyInstaller onefile/windowed,
вход installer/dump_app.py, пути модулей work и installer. Тесты:
`python -m unittest discover -s installer -p test_dump.py -v`.
Проверка EXE без команд устройству: `XREAL-Dump-0.1.exe --self-test report.json`.
