# XREAL One: Pilot 2.0

Актуальный кандидат описан в [корневой инструкции](../README.md) и [таблице совместимости](compatibility.md). Для него используются `XREAL-Russian-Updater-0.7.0-rc1.exe` и `XREAL-one-Pilot2-RU-0.7.0-rc1.bin`.

Физическая проверка на обычном One ещё не выполнена. BIN сохраняет GF-профиль One, не включает Hebe или разгон и требует совпадения системного ABI до записи. При несовпадении требуется исследовать библиотеки и видеопамять конкретного One; снимать проверку модели для обхода ошибки не следует.

`v0.6.0-one-test`, `work/build_one_features.py` и `installer/build-one-test.ps1` — исторический эксперимент. Для 0.7 используется общий `firmware/build.py`; не запускайте старый скрипт для получения нового EXE.
