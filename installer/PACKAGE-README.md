# XREAL 0.7.0-rc1: кандидат для испытаний

Скачайте общий `XREAL-Russian-Updater-0.7.0-rc1.exe` и только один BIN:

- `XREAL-one-pro-Pilot2-RU-0.7.0-rc1.bin` — One Pro X1112010, профиль Hebe/Gina с пределом luminance 500.
- `XREAL-one-Pilot2-RU-0.7.0-rc1.bin` — обычный One, профиль GF без переноса яркости Hebe.

Это новые кандидаты, аппаратная проверка именно этих сборок ещё требуется. Работа на One и стабильные 60 кадров/с не подтверждены. Исправлены полный RGB LUT, смещение цвета в Real3D и время жизни рабочих потоков. Частоты 133/240 Гц, EDID и системные разделы не изменяются.

Запустите EXE, выберите очки, выберите BIN, прочитайте описание и нажмите установку. Дождитесь чтения и проверки всех файлов. Для повторного чтения используйте «Проверить без записи». Автоматического отката нет.

Инструкция: https://github.com/Skiters/xreal-one-pro-russian
