# Русское меню для XREAL One, One Pro и 1S

Проект переводит экранное меню очков на русский. Русский занимает место польского языка, английский остаётся доступен. Для One и One Pro есть также варианты на базе Pilot 2.0 с дополнительной обработкой изображения. Установка меняет компонент Pilot. Системная прошивка, DSP и калибровки очков сохраняются.

### Прошивка, диагностика и дамп

- **Дамп в основном приложении.** Выберите очки и папку сохранения. Программа считывает доступные через USB файлы и сохраняет исходные ответы, распакованные файлы и `report.json`. Отчёт показывает, какие запросы выполнились, где произошла ошибка и какие системные библиотеки совпали с эталоном. Данные остаются у вас. Полнота зависит от прошивки очков.
- **Нативный интерфейс Mac.** Прошивка, диагностика и дамп используют общий код проверки BIN и чтения USB. После перезапуска очков на Mac приложение может продолжить проверку при смене USB-пути, если однозначно находит устройство по модели и серийному номеру.
- **Распознавание SKU.** Установщик понимает поддерживаемые идентификаторы в ASCII и UTF-16. Неизвестные ревизии можно исследовать через сбор дампа. Для записи по-прежнему нужна совместимая комбинация модели, SKU и версии.

## Что изменилось в экспериментальной One Pro 0.7.1

**AI HDR.** Адаптер обрабатывает цвет по трёхмерной таблице в четыре потока. В новой сборке процессор заранее запрашивает следующие элементы таблицы. Цель — сократить ожидание памяти при движении изображения. Каждые 60 обработанных кадров адаптер записывает замеры времени, чтобы сравнивать сборки на одной сцене. Реальный прирост FPS этой версии пока неизвестен.

**Real3D.** В меню есть две отдельные строки. Обе используют карту глубины Pilot 2.0. «Real3D One Pro» строит стереоизображение штатным алгоритмом One Pro, «Real3D Pro+» использует перенесённый алгоритм с обработкой на CPU. Глубина регулируется отдельно. В варианте Pro+ соседние пиксели обрабатываются группами. В тестах результат совпал побайтно. Переключать алгоритмы можно прямо в очках.

**Меню и режимы изображения.** У строк Real3D одинаковые отступы. Таймеры обновления меню и анимации настроены на 16 мс, переходы сохраняют штатную длительность. «Чтение» и «Кино» входят в сборку. Для панели применяется профиль One Pro. Число 500 в настройке яркости обозначает параметр профиля. Измерения яркости в нитах для этой сборки нет. Штатные настройки вывода предусматривают 90 Гц для обычного режима и 60 Гц для синтетического стерео. Режимы 133/240 Гц в опубликованных пакетах отсутствуют.

В исходниках появилась возможность собрать обе строки Real3D также для обычных One. Доступный выше BIN One 0.7.0 содержит прежний вариант. Проверка второго алгоритма и видимой глубины на One ещё предстоит.

## Установка и проверка

1. Подключите очки к компьютеру USB-кабелем с передачей данных. Закройте другие обновляторы и вкладку обновления XREAL.
2. Запустите установщик, выберите очки и укажите BIN для своей модели. Установщик проверит содержимое BIN, USB-модель, SKU и версии. Для сборок Pilot 2.0 с описанием сборки он дополнительно сверяет системные библиотеки и доступную видеопамять.
3. Нажмите кнопку установки и оставьте кабель подключённым до окончания проверки. После передачи и перезапуска программа считывает файлы с устройства и сравнивает контрольные суммы.
4. Подключите очки к источнику видео. Выберите русский в меню языков. При проверке AI HDR сравните одну движущуюся сцену с SDR. Для Real3D проверьте глубину на ближних и дальних предметах и возврат в обычный режим.

Поддерживаемая системная версия — **15.1.03.603_20260914**. Для One и One Pro установщик распознаёт Pilot **1.9.1.20260914175625** и **2.0.0.20260920102250**, для 1S — первую из них. Windows EXE распространяется без цифровой подписи. Хеш последнего экспериментального BIN доступен на [странице экспериментального выпуска](https://github.com/Skiters/xreal-one-pro-russian/releases/tag/one-pro-hdr-0.7.1). Для файлов прошивок 0.7.0 используйте [контрольные суммы базового выпуска](https://github.com/Skiters/xreal-one-pro-russian/releases/download/v0.7.0/SHA256SUMS.txt).

## Если что-то пошло не так

Откройте «Диагностика / отчёт об ошибке…». Кнопка «Проверить сейчас» считывает модель и версии, а при выбранном BIN также проверяет совместимость. Если ошибка возникла при обратном чтении, переподключите очки, выберите тот же BIN и нажмите «Проверить без записи».

Для разбора ошибки приложите просматриваемый текстовый отчёт с этапом, сообщением и хешем BIN. Для сообщения о качестве изображения укажите модель, сборку, источник видео, выбранный режим и что вы увидели. [Создать обращение](https://github.com/Skiters/xreal-one-pro-russian/issues/new).
