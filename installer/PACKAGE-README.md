# XREAL One / One Pro — русские прошивки

В ZIP лежат отдельные файлы: `XREAL-Russian-Updater.exe` и два BIN. Распакуйте ZIP в одну папку, запустите EXE, выберите очки и нажмите «Выбрать BIN…». Приложение проверяет SHA256 выбранного файла и модель очков до записи. Интернет после скачивания не нужен.

- `XREAL-One-RU-Pilot1.9.1.bin` — русский Pilot 1.9.1 для XREAL One и One Pro. Официальный пакет Pilot 1.9.1 для обеих моделей имеет одинаковый MD5; русская модификация основана на нём. На One перевод ещё не проверен физически.
- `XREAL-Pilot2-RU-Hebe-Real3D-CPU.bin` — экспериментальная русская Pilot 2.0 только для One Pro SKU `X1112010`: AI HDR, режимы «Чтение»/«Кино», Real3D. Последний даёт небольшую глубину и около 53–55 обработанных кадров/с на проверенном устройстве.

Русский занимает место польского языка; английский остаётся. Не отключайте кабель до завершения записи и проверки файлов. Если запись принята, но проверка прервана, переподключите очки и нажмите «Проверить без записи» с тем же BIN. ZIP содержит `SHA256SUMS.txt` для проверки файлов.

Подробности и исходники: https://github.com/Skiters/xreal-one-pro-russian
